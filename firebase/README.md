# Firebase ayarları

Proje kurulduğunda Firestore Rules, indeksler ve emulator yapılandırması burada tutulacak. Şimdilik canlı Firebase projesi veya erişim kuralı oluşturulmadı.

Skor/haber/rol/moderasyon verisini yalnız yetkili backend yazar. Kullanıcı kendi izinli verisine erişir. Chat yazımı backend üzerinden, oda durumu ve hız kontrolüyle yapılır. Kurallar emulator'da yetkisiz erişim senaryolarıyla doğrulanacak.
